# Banco de plantillas y precedentes — Fernando

## Restricción explícita de JC (ver `.claude/agents/fernando.md`)

JC quiere alimentar este banco con SUS PROPIAS plantillas de contrato para
usarlas como base real, nunca un formato genérico ni de corte americano.
Todavía no tengo esas plantillas base para ninguna de las tres líneas de
entrada, así que **no redacto texto sustantivo de contrato en esta
entrega**. Lo que sí dejo es la estructura del repositorio y el inventario
de qué falta por línea de servicio, para que en cuanto JC comparta sus
documentos reales, la redacción se pueda incorporar directamente en el
lugar correcto sin reorganizar nada.

Ningún documento de este banco, cuando se redacte, usará estructura o
terminología de common law ("Agreement", "Whereas"); todo en formato
mexicano (declaraciones, cláusulas, jurisdicción CDMX).

## Estructura del banco (peso equivalente entre las tres líneas)

```
plantillas/fernando/
├── constitucion/                      → Constitución y Estructuración Corporativa
│   └── PENDIENTE.md
├── contratos-mercantiles-civiles/     → Contratos Mercantiles y Civiles
│   └── PENDIENTE.md
└── cumplimiento-laboral/              → Consultoría y Cumplimiento Laboral (REPSE, NOM-035)
    └── PENDIENTE.md
```

## Inventario pendiente, por línea

| Línea | Documentos base que necesito de JC | Estado |
|---|---|---|
| Constitución y Estructuración Corporativa | Acta constitutiva tipo, poderes, actas de asamblea | Pendiente — sin documento base |
| Contratos Mercantiles y Civiles | Contrato de prestación de servicios, NDA, contrato de distribución/comisión mercantil (según los casos reales que JC haya trabajado) | Pendiente — sin documento base |
| Consultoría y Cumplimiento Laboral (REPSE, NOM-035) | Contrato de subcontratación especializada (REPSE), política NOM-035 tipo | Pendiente — sin documento base |

## Cómo avanzar esto

En cuanto JC comparta al menos un documento real por línea, lo uso como
plantilla base, extraigo la estructura de cláusulas y declaraciones que ya
usa, y la reemplazo en el archivo `PENDIENTE.md` correspondiente por la
plantilla real. No voy a inventar una plantilla "definitiva" antes de eso.
