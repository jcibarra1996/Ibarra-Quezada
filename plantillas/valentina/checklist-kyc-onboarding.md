# Checklist — KYC ligero y onboarding (prospecto interesado → cliente activo)

Incorpora el SLA de Diego (48h general, 24h si urgencia o constitución).
No se factura nada hasta que se firme la Carta de Honorarios.

## 1. Al cerrar la llamada de descubrimiento (Diego)

- [ ] Datos de contacto completos del decisor (dueño / director general)
- [ ] Línea de entrada identificada (constitución / contratos /
      cumplimiento laboral)
- [ ] Señales de upsell anotadas, sin ofrecerlas todavía
- [ ] Urgencia marcada sí/no → define si aplica SLA de 24h

## 2. KYC ligero (antes de enviar propuesta)

- [ ] Razón social o nombre completo del prospecto
- [ ] Giro de la empresa y tamaño (empleados)
- [ ] Verificación rápida de que no hay conflicto de interés con clientes
      actuales del Despacho
- [ ] Confirmar que el decisor con el que se habló tiene autoridad real
      para contratar

## 3. Envío de propuesta (dentro del SLA)

- [ ] Propuesta enviada dentro de 48h hábiles (o 24h si aplica)
- [ ] Propuesta referencia el Método IQ y el alcance específico acordado
- [ ] Propuesta menciona que litigio queda fuera de alcance directo

## 4. Cierre

- [ ] Carta de Honorarios enviada con Anexo 1 (propuesta) adjunto
- [ ] Carta de Honorarios firmada por ambas partes
- [ ] Alta en el tracker de Camila como cliente activo (deja de ser
      prospecto)

## 5. Primera entrega

- [ ] Confirmar con el cliente el canal y frecuencia de comunicación
- [ ] Primer entregable conforme al Método IQ: Diagnóstico
